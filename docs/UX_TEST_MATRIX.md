# UX regression matrix

- Offline launch does not require a profile.
- Online entry requests identity once and supports cancel.
- Challenge and rematch affordability follows the selected difficulty.
- Career chapter navigation renders ten levels.
- Career, practice and daily sessions resume after process restart.
- Loss flow supports Coin, rewarded ad, restart and save/exit.
- Completion flow supports next, replay, menu and optional reward.
- Friends, requests, challenges and recent opponents are reachable.
- Daily rewards are reachable without first failing matchmaking.
- iOS shows Game Center; Android shows Google Play Games.
